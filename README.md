# Perfect Chess Games

Every move White can open a chess game with, and every reply Black has to each of them:
twenty by twenty, four hundred games. Stockfish played all of them out.

**[Browse the games →](https://xavierdpt.github.io/perfectchessgames/)**

The page lists them best first — White's openings by the engine's score, and under each one
Black's replies the same way — with the PGN of every game and a button to copy it. Each game
also carries the part and timestamp of the video it appears in.

The page is generated by `make-pgn-index.py` in the
[fenkbsan2](https://github.com/xavierdpt/fenkbsan2) repository, which holds the engine, the
analysis and the video pipeline. This repository is only what gets published.
